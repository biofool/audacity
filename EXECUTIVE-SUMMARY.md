# Executive Summary

## What this project is

This repository is **Audacity 4**, the open-source, multi-track digital audio editor and recorder. It is a major rewrite of the long-established Audacity audio editor, currently in active development toward a new Qt-based user interface while preserving the core audio engine.

## Benefits for somatic studios and fields

Somatic practitioners, movement teachers, and small wellness studios can use this tool for everyday audio work without relying on subscription-based commercial software.

### Teaching and class content

- Record live classes, workshops, and guided sessions directly into a multi-track project.
- Edit verbal cues, pacing, and breath markers with a visual waveform view.
- Layer background music, ambient sound, or voice instruction on separate tracks.
- Export finished audio in common formats for students to stream or download.

### Podcasts and instructional media

- Produce interview-style podcasts with multiple microphones on separate tracks.
- Normalize uneven voice levels and reduce background noise before publishing.
- Add intros, outros, and chapter-like labels for long-form guided content.
- Generate files suitable for podcast hosting platforms and course sites.

### Accessibility and cost

- Open-source license (GPLv3) means no per-seat or recurring licensing cost.
- Runs on Windows, macOS, and Linux, so studios are not locked into one operating system.
- Supports standard audio interfaces and plug-in formats, making it compatible with common studio hardware.

## Important caveat

This `master` branch targets Audacity 4, which is still under heavy development and is not yet a stable release. Studios that need a production-ready editor today should use the released Audacity 3.x builds instead.
